Install an I2P router

eepview found no I2P router on this computer, so it can install one now.

What does this mean?

eepview opens eepsites only through an I2P router that runs on your computer. The router hides who you are by sending each request through several other routers. eepview downloads it once, over the clearnet, and checks each file against its signature before it runs. Then the router joins the network and builds tunnels, which takes 2 to 10 minutes the first time. After that, every request goes over I2P.

Building tunnels

Your router is joining the network, which takes 2 to 10 minutes the first time.

What does this mean?

A tunnel is a path through three other routers. Your router needs one tunnel out and one tunnel in before it can open a site. Later starts take less than a minute. You can close this window, and eepview tells you when it is ready.
