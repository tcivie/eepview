Interface review

Every internal page, filled by the dev mock backend. The theme you pick here applies to all of them. Each page also has light and dark links that do not change your saved choice.

First start

  • No router found, install offer Download size, sources, Java choice, permissions. LightDark
  • Download and verify Progress per file, then the signature check. LightDark
  • Download failed A file did not match its signature. Nothing was installed. LightDark
  • Building tunnels The first start, 2 to 10 minutes. LightDark
  • Tunnels stalled No tunnel after 10 minutes, with the router log. LightDark
  • Ready What was set up. LightDark
  • Router found on this computer Use the running router, or install a separate one. LightDark
