# eepview artwork: license and origin

## What this folder holds

Every file in `assets/brand/` and the generated icons in `src-tauri/icons/` are original
work made for eepview. They contain no I2P artwork. Nothing was copied, traced, or
redrawn from the I2P logo or from the I2P mascot "itoopie".

The artwork is released under the same license as the rest of this repository (MIT, see
`LICENSE`). The name "eepview" and the eepview mark identify this project. Do not use them
in a way that suggests that a fork or another product is eepview.

## Why the mark does not reuse I2P artwork

We checked the terms of the I2P logo and of itoopie before we started (October 2026):

| Source | What it says |
|---|---|
| [i2p.net Press & Media](https://i2p.net/en/about/media/) | Credit "The Invisible Internet Project (I2P)". The mascot is "free to use in presentations and tutorials". "Resize as needed, but don't alter design or colors." |
| [i2p/i2p.graphics README](https://github.com/i2p/i2p.graphics) | `logo/` is "Copyright (C) The I2P Project" with no license. Other works are CC BY 4.0. |
| [i2p/i2p.i2p LICENSE.txt](https://github.com/i2p/i2p.i2p/blob/master/LICENSE.txt) | The router console logos are "Copyright (c) 2019 The Invisible Internet Project. All rights reserved." and also CC BY-SA 4.0. |
| [i2p/i2p.www LICENSE.txt](https://github.com/i2p/i2p.www/blob/master/LICENSE.txt) | Website images are CC BY-SA 4.0. |

The terms disagree with each other. The project's own usage guide forbids changes to the
design, and an app icon that combines the logo or the mascot with a browser window is a
change. A share-alike license on a derived mark would also bind the eepview brand. Finally,
an icon built from the official I2P art could look like an official I2P product, which
eepview is not.

So the eepview mark only refers to I2P through an idea: garlic routing, the technique I2P
uses to bundle several encrypted messages ("cloves") into one. The mark shows a garlic bulb
of three cloves inside a browser window. The garlic is drawn from scratch and does not
resemble any I2P artwork. The wordmark is "eepview". It does not use the I2P name.
